# 中国传统色配色 Skill

Chinese Traditional Color Palette Skill

这是一个帮助 AI 运用中国传统色，为图片中的包装、服装、海报、招牌、建筑和街景等对象探索配色方案的 Skill。我希望它能让更多人把传统色用进自己的工作，也用进日常生活。

## 开始使用

当前版本：**v0.11.0-rc.2，公开测试版**。仓库名为 `chinese-traditional-color-palette`，Skill 内部名称仍为 `traditional-color-palette`。

1. 下载仓库，或从 Releases 下载 Skill ZIP 包。解压后，让你的 Agent 加载 `SKILL.md`；支持 Skill ZIP 导入的平台可按平台说明导入。
2. 准备 Python 3.10+，在 Skill 目录中执行 `python3 -m pip install -r requirements.txt`。
3. 确认 Agent 能读图、运行本地脚本并使用真实的图像编辑工具。提供图片，说明想改善什么、需要保留什么，以及本轮要五张还是十张。

首次运行前，可用以下命令查看脚本入口：

```bash
python3 scripts/scene_cli.py --help
```

Python 脚本负责计划、预算、记录和对比页，图像生成由宿主 Agent 的图像工具完成。其他平台需要适配自己的工具。详细操作见 [使用说明](USAGE.md) 和 [包说明](PACKAGE-NOTES.md)。

## 为什么想做这件事

六年前，我的一位亦师亦友的兄长，郭浩先生，做了一件很有意义的事。他从故宫文物中提取颜色，追溯这些颜色在古代的来源，结合诗词古籍中的意境，写成了《中国传统色：故宫里的色彩美学》。

这本书由中信出版社出版，销量超过了 50 万册。我也买过不少，送给做设计的朋友。

我是一个理工男，没有接受过绘画和审美训练。喜欢这些颜色，却常常不知道该怎样搭配。看到街景、招牌、海报，甚至交通工具和房屋外墙上不够协调的配色，我总会想：能不能把中国传统色的美，带进这些日常场景？

在我看来，随着生活条件改善，我们正在对生活环境提出更多审美要求，而中国传统审美中有许多值得学习和使用的经验。我曾在知乎谈起这个想法，获得了几十万阅读，也让我感到，关注这件事的人确实不少。

前段时间，再次见到郭浩先生，我萌生了一个更具体的想法：能不能做一个自动化配色的 Skill，让 AI 帮我们试出这些场景的其他可能？

## 这个 Skill 能做什么

Skill 可以理解为交给 AI 的一套工作方法。你提供图片，说清想改善什么、希望保留什么，它就围绕这些目标分析配色，提出不同方向，生成效果图，并把原图和方案放在一起比较。

它使用项目整理、校对的 384 色色表，每轮可以选择五张或十张方案。你看完以后，也可以提出具体反馈，再继续调整。

比如，可以这样提出任务：

> 请用中国传统色，为这个包装做五个配色方案。保留文字内容和盒型，让整体更明亮、亲和。把原图和结果放在一起，说明各方案的主要变化。

你不必先背下色名。可以先看结果，再表达自己的偏好。

## 两个让我改变思路的片段

做起来以后，我才发现，选出有出处的颜色，和把一件东西配好，是两项不同的工作。

有一次，我想调整果蔬玩具的配色，AI 却把注意力放到了篮子上。它确实改了颜色，但改错了重点。因此，我把流程调整为先明确主要对象和目标，再处理颜色之间的关系，最后选色、出图和检查结果。

另一次是在 Coze 测试鸡蛋包装。第一轮的方案被模型评为可用，我看完却觉得“整体来说过于暗沉”。第二轮便改走浅绿、暖黄和奶油色等方向，并同步加深文字颜色。同一个盒子，有了更明亮的样子，也让我看到了反馈怎样真正改变设计。

前后经历上百次调整、迭代，有些不满意的部分又重新设计，才逐渐形成现在的版本。我希望留下的，是一套能帮助人比较和选择的配色方法。

## 当前版本，以及我的邀请

这个 Skill 最初在 Codex 上编写，我也放到 Coze 上，让第三方 Agent 做了实际验证，效果似乎还可以。它已有 Codex 之外的使用案例；换到其他 Agent，仍需要具备读图、图像生成和文件处理能力，并实际测试。

如果由我自己打分，现在大概是一个 60 分的“小学生版本”：已经可以尝试使用，也还有不少粗糙之处。生成图偶尔会偏离要求，部分方案未必好看。尤其是包装、印刷等用途，效果图适合比较方向，不能直接当成生产稿。

我把它放出来，是希望大家试一试。欢迎提供图片和使用案例，指出哪里不合适，提出改进建议，也欢迎一起参与完善。

**这个 Skill 得到了郭浩先生的授权和支持。推广中国传统审美，是他的心愿，也是我的心愿。**

我期待，有一天，它能帮助更多人把中国传统色用进自己的生活，让全世界都能看到大美中国色。
