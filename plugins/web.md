# 网页与界面

按背景、内容、操作和状态组织颜色；保留照片、品牌或文字内容时分别判断颜色权限。避免整屏滤色代替元素设计；不默认白底或单一焦点。

主控须保留任务内文字与必要控件的实际配对和可见状态检查，原色保留也不能跳过。按[评审指南](../references/evaluation.md)计算适用对比；缺字号、字底或状态证据就标未知，不能用空检查表宣称通过。

看阅读层次、操作识别和整体气质。截图是概念交付，不证明页面已实现、未知 CSS 或整站合规；功能对比通过不等于美观。
