# 真实生成与交付

按当前 imagegen Skill 使用内置工具；不可用就报告，不用程序拼色冒充效果图。

提示只带目标、本款行动、本轮反馈应用、区域色号、必要保护和纠正。生成前对照 design_logic 核对实际提示：颜色与区域是否兑现关系，关键部位改色或保留是否明确；purpose 不单独进入提示。遗漏先修计划再编译，不另改冻结提示。无需带理论全文或其他候选；归属、图片层次、小面积目标和实际字底不能压掉，保护形态不限制授权改色。

预登记后按冻结提示和同一原图独立生成，不串用上一款；附旧图修复时说明作用。真实登记成功或失败，不伪造路径和调用证据。

需求与5/10数量已答即执行，不追加“开始生图”审批。test模式禁止真实图像工具；pending恢复先核对回执，不重发。CLI返回下一步不代表图像已产出。历轮偏好图只作配色参照，原图保持形态基准。

打开当前图评审；设计变化先改计划，新图不继承旧接受。导出当前结果，图先、详情折叠、失败标明；不在效果图上另加标题、图例、水印或色号。

每轮交付（包括partial）后主动问继续还是结束；继续须有明确意愿、下一轮数量及反馈或无新意见。结束后停止生成。
