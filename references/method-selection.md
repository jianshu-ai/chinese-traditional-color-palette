# 按问题选择方法

先找妨碍目标的关系，再选足以处理它的少数方法。六组可以合用，不要求逐组使用或每款一种；具体对象、材料与功能条件沿用插件。以下操作可直接用于设计，来源索引仅供追溯。

| 方法 | 何时考虑 | 可尝试的操作与边界 |
| --- | --- | --- |
| 明暗与图底 | 主体弱、层次糊 | 调整主体与承托区域的深浅，把明暗差放在需要辨认的位置；检查是否同时突出杂乱细节，避免只提高全图反差。 |
| 共同色调与属性 | 多区域松散 | 让大面共享相近鲜灰或明暗范围，用局部差异保持层级；共同属性不必是同色相，不把各角色都压进同一片中灰。 |
| 面积、主次与重复 | 多处争抢注意 | 收拢强色、建立主导色面，把强调集中或有序重复；同时看位置与分布，不规定通用比例或色数。 |
| 邻接、边界与尺度 | 色板好看，落图失效 | 在获准范围调整谁与谁接触、现有边界的强弱和重复色的密度；按使用尺寸与距离重看，不擅改轮廓或新增纹样。 |
| 有限色域与颜色角色 | 选色随意、关系难维持 | 先分主体、承托、结构、强调等必要角色，限定相应可选属性，再从冻结色表匹配；限色不牺牲必要识别与题材特征。 |
| 参考关系与场景转译 | 气质不合、方向不明 | 从参考提取主次、明暗极值、强色位置、邻接和材质关系，适配当前用途与保持项；古色名称不证明历史复原，参考色号不直接照搬。 |

## 两个迁移短例

陈列中小器物与背板明暗接近，可能使轮廓难辨。若背板获准改色，可保留器物色、调整背板深浅；也可保留背板，拉开器物与底座的关系。看缩小后的轮廓是否清楚，若只让底座更抢眼，原假设需修正。可迁移到人物与环境、商品与展示底。

用户说“喜欢B，但重点不够突出”。事实是对B的偏好与重点问题；“喜欢其共同色调”只是暂定解释。可保留B的大面色调，分别尝试局部明暗差或把分散强调集中到目标处，落实到具体区域再比较；无须先逼问喜欢原因。

例子只演示推理，不指定任何原图的固定答案。方法效果须回到当前成图，按[评审](evaluation.md)回看假设；功能通过与关系计算均不等于美观。
